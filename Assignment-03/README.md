### Task 3: text-format.html
**Problem Statement:**
> Create text-format.html with two paragraphs of any text. Use strong and em on one word each, and put a line break inside one paragraph.

**Source Code:**
```html
<!--
  Name: Anant Pratap Singh
  Student ID: BCS2025542
  Institution: Invertis University, Bareilly
  Course: B.Tech CSE - Second Year
  Subject: HTML and CSS Introduction Lab (BCS352)
  Assignment: 3 - Your First HTML Page
  Task: 3
-->
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Text Formatting</title>
</head>
<body>
  <p>HTML allows you to emphasize <strong>important</strong> words using the strong element.<br>
  This sentence appears on a new line within the same paragraph thanks to the line break tag.</p>

  <p>You can also express <em>emphasis</em> on specific terms using the em element.</p>
</body>
</html>
```

**Output / Result:**
```text
Strong tag renders bold, em tag renders italic, and br creates a line break within the paragraph.
```
