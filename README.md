## 🚀 How to Run the Programs

### Viewing HTML & CSS in Browser
For all HTML & CSS tasks:
1. Open any `.html` file directly in your web browser (Google Chrome, Microsoft Edge, Firefox).
2. Or in **Visual Studio Code**, right-click any `.html` file and select **Open with Live Server**.
3. Use developer tools (`F12`) to inspect elements, test responsiveness, and verify media query breakpoints.
